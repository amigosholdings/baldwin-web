Photo guide

Take the same photo every time.

Use the same lighting, distance, framing, and hair state so later photos are easier to compare.

HairSame state: dry/dry, wet/wet, product/no product.
RoomUse the same spot and primary light source.
CameraSame lens, approximate distance, height and orientation.
TimingNote recent haircuts and major setup changes.

Before each check-in

Match fixed landmarks in frame. If you cannot reproduce the setup, write down what changed instead of treating the photos as perfectly comparable.
